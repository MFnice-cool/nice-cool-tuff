# Спринт 3 — Библиотека модпаков: почему UI неудобен тестировщикам и что исправлено

Дата: 2026-09-11
Ветка: `arena/01a08f1a-tuffbox-build-test`
Файл: `apps/tuffbox-desktop/src/components/Library.svelte` (страница Library: «Your packs» / «Discover» / «Create»)

---

## Диагноз: 8 причин, по которым страницу тяжело проверять

### U1. Таб-переключатель «прыгает» при смене вкладки
На «Your packs» полоска вкладок рендерилась **внутри тулбара списка инстансов** (`LibraryInstancesPane → .tb-leading`), на «Discover»/«Create» — в отдельной строке `.library-subnav` над контентом. Каждое переключение вкладки визуально перемещало один и тот же контрол: у него другой отступ, другая высота строки, другая рамка. Тестировщик фиксирует это как баг каждый прогон; вдобавок **кнопка Import была недоступна на вкладке «Your packs»** — чтобы импортировать пак, нужно было сначала уйти на другую вкладку.

### U2. Вкладки — не настоящие вкладки для автоматизации и скринридеров
Контейнер имел `role="tablist"`, но кнопки — без `role="tab"`, `aria-selected`, `aria-controls`; панели — без `role="tabpanel"`/id; стрелочная навигация отсутствовала. По accessibility-tree нельзя определить активную вкладку; автоматика по роли tab не работает.

### U3. Ноль test-хуков
Во всём каталоге компонентов `data-testid` не встречался ни разу — селекторы UI-тестов приходилось строить по хрупким CSS-цепочкам, которые ломаются от любой правки стилей.

### U4. Состояние поиска ненаблюдаемо
После поиска нигде не видно: сколько найдено, по какому запросу, какой каталог отвечал (в режиме «Both» результаты чередуются незаметно). Empty state «No packs found — Try a different search» не повторял запрос. QA приходилось считать карточки глазами, чтобы понять, применился ли поиск.

### U5. Строка «Download to» теряла введённый путь
- Enter в поле **не сохранял** путь (только кнопка Save) — типовой сценарий QA «вписал → Enter → проверил» молча ничего не делал;
- индикатора «изменено, не сохранено» не было;
- `browse` сохранял сразу, `Save` — вручную: два разных контракта у соседних кнопок;
- отрицательный `margin: -8px` налезал на тулбар выше.

### U6. Меню импорта без a11y-состояний
Триггер без `aria-haspopup`/`aria-expanded`; Escape закрывал меню, но **не возвращал фокус** в кнопку — клавиатурный сценарий терял место.

### U7. Карточка пака — ловушка вложенной интерактивности
Карточка была `role="button"` + `tabindex="0"` с собственным onclick/onkeydown, **внутри** неё — три настоящие кнопки (открыть, Page, Add). Вложенная интерактивность: AT читал карточку одной кнопкой, клавиатура получала двойные стоп-точки, автотесты по `role=button` кликали неоднозначно.

### U8. Темы и прозрачность (специфика задачи)
- **Glass-переключатель (`data-glass="on"`) красил только `.tb-card`**: тулбар Discover, меню импорта, панели empty/loading оставались непрозрачными — страница выглядела наполовину сломанной при включённой прозрачности.
- **Пилюли 999px не сплющивались в sharp-темах**: win95/pixelato определяют токены радиусов `0px`, хардкод обходил систему — круглые вкладки среди квадратного UI.
- **Белая буква-заглушка на обложке была нечитаема** поверх «тёплых» акцентов (Solar #ffc500, amber #f59e0b, light-темы): контраст белого по жёлтому ~1.6:1. Тема-свип (обязательный QA-сценарий) падал на половине тем.
- **`.mini-spinner` был захардкожен чёрным** (`#000`/rgba(0,0,0,.25)) — невидим на тёмных поверхностях; вариация `.dark` решала это угадыванием по месту вызова.
- **`.create-plus.import` — синий rgba(59,130,246) вне темы** (в большинстве тем акцент не синий), border browse — захардкоженный amber; `.plus-ring` — литерал 14px вместо токена (не сплющивался в sharp-темах).

## Что исправлено

| # | Фикс |
|---|------|
| F1 | **Стабильная секционная панель**: `.library-subnav` (вкладки + Import) рендерится всегда, на всех трёх вкладках, в одной позиции. Таб-стрип больше не перемещается; Import доступен из списка паков. Дублирование вкладок внутри тулбара паков убрано (`toolbarLeading` больше не передаётся). |
| F2 | **Настоящая tablist-семантика**: `role="tab"` + `aria-selected` + `aria-controls` + id; панели — `role="tabpanel"` + `aria-labelledby`; **стрелочная навигация** Left/Right/Home/End с roving focus (WAI-ARIA tabs). |
| F3 | **31 `data-testid`-хук**: `library-tab-*`, `library-panel-*`, `library-import-*`, `library-provider-*`, `library-search-input/btn`, `library-results-status`, `library-download-*`, `library-result-card/open/page/add`, `library-loading`, `library-empty`. Плюс `data-provider` на карточках для проверки провайдера. |
| F4 | **Наблюдаемое состояние поиска**: статусная строка `role="status" aria-live="polite"` — «N packs · Modrinth X · CurseForge Y · for "query"»; empty state эхо-повторяет запрос и провайдер; loading получил крупный спиннер + `role="status"`. |
| F5 | **«Download to»**: обёрнута в `<form>` — **Enter сохраняет**; индикатор «· unsaved» (accent-warning) при несохранённом пути; Save disabled без изменений; отрицательный margin убран. |
| F6 | **Меню импорта**: `aria-haspopup="menu"` + `aria-expanded` на триггере; Escape возвращает фокус в кнопку. |
| F7 | **Карточка** — `<article>` без `role="button"`/tabindex: клик мышью по карточке остался (удобство), клавиатурный путь — реальные кнопки внутри; предупреждения a11y-компилятора устранены аннотациями с обоснованием. |
| F8 | **Темы/прозрачность**: страница отвечает на glass-переключатель целиком (тулбар, меню, empty/loading — тот же рецепт, что `.tb-card` в themes.css; sharp-темы сохраняют заливку; potato-pc — без blur); радиус пилюль через `--lib-pill-radius` (0px в win95/pixelato); буква-заглушка получает тёмный скрим в letter-режиме → белый текст читаем на любом акценте; спиннер на `currentColor` (сам подстраивается под `--on-accent`/`--accent-primary`); create-import переведён на `--accent-secondary`, browse — на `--accent-warning` (color-mix); `.plus-ring` — токен радиуса. |

## Скрипт ручной проверки для QA (после мержа)

1. Переключить все 18 тем — вкладки/пилюли сплющиваются в win95/pixelato, буквы на обложках читаемы везде, спиннеры видны везде.
2. Settings → Appearance → Glass transparency: включить — тулбар Discover, меню импорта и empty-панели становятся стеклянными вместе с карточками (win95/pixelato — остаются матовыми — это намеренно).
3. Discover: ввести запрос → статусная строка показывает N и запрос; очистить → empty-state повторяет запрос.
4. «Download to»: изменить путь → появляется «· unsaved»; Enter или Save → тост и сброс индикатора.
5. Импорт: кнопка видна на всех трёх вкладках; Escape из меню возвращает фокус на кнопку; `aria-expanded` переключается.
6. Клавиатура: Tab → фокус-кольца; стрелки ←/→ переключают секции; карточки не перехватывают Tab (внутри — кнопки).

## Осталось (бэклог)
- Пагинация/«Load more» для Discover (сейчас первые 30 результатов Modrinth / офсет CurseForge).
- Вынести Discover в отдельный ленивый компонент (уменьшение Library.svelte).
- Фильтры по версии игры/лоадеру в поиске модпаков.
